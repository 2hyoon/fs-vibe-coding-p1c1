# Pomodoro Timer

A minimal Pomodoro timer built with vanilla HTML, CSS, and JavaScript. No framework, no build step.

## Features

- 25-minute work sessions with 5-minute breaks
- Automatic mode switching (Work → Break → Work)
- Configurable session durations via Settings panel
- Daily session log persisted in `localStorage`

## Usage

Open `index.html` directly in a browser.

## Development

```bash
npm install     # install ESLint
npm run lint    # lint app.js
npm test        # placeholder (no tests yet)
```
